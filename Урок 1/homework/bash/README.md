# Bash-скрипти з вводом користувача

Три скрипти для другої частини домашнього завдання. Усі працюють з тим, що вводить
користувач, — команда `read` кладе набраний текст у змінну.

| Файл | Що робить | Що показує |
| --- | --- | --- |
| `hello.sh` | питає ім'я та вік, вітається і рахує рік народження | `read`, перевірка на порожній ввід, `if/else`, арифметика `$(( ))` |
| `new_project.sh` | питає назву проєкту і створює заготовку папок та файлів | питання «так/ні», перевірка `-d` (чи існує папка), `mkdir`, `touch` |
| `calc.sh` | калькулятор: два числа і дія, працює в циклі | `while`, `case`, захист від ділення на нуль |

## Запуск (Git Bash)

```bash
cd "d:/PY/Урок 1/homework/bash"
bash hello.sh
bash new_project.sh
bash calc.sh
```

Або зробити файл виконуваним і запускати напряму:

```bash
chmod +x hello.sh
./hello.sh
```

## Що варто запам'ятати

- `read -p "Питання: " змінна` — вивести підказку і дочекатися вводу.
- `"$змінна"` у лапках — обов'язково, інакше пробіли у введеному тексті зламають перевірку.
- `[ -z "$x" ]` — «чи порожня змінна», `[ -d "$x" ]` — «чи існує така папка».
- `$((a + b))` — арифметика в bash (працює лише з цілими числами).
- `case ... esac` — вибір з кількох варіантів замість довгого ланцюжка `if/elif`.
- Введене користувачем **завжди перевіряй**: люди помиляються і вводять букви замість цифр.
